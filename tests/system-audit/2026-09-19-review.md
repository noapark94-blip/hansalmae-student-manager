# System review — 2026-09-19

Baseline: `67aaf25f6e2586d684d952d72314dff7e3624dde` (latest main at start).

## Fixed

- Tuition month requests could resolve out of order, displaying the previous month's rows under the selected month. Results are now scoped to the month and Supabase client, late/unmounted requests are ignored, and failed requests clear old rows. A retry control handles failed reads.
- Operations analytics requests could overwrite a newer period. Partial analytics/audit failures could display a misleading all-clear state. Both reads now succeed together, stale responses are ignored, transport failures stop loading, retained data is identified as the previous result, and CSV export is disabled for stale/failed results.
- No layout/CSS redesign, backend data mutation, schema change, notification delivery, or real financial test transaction.

## Verified

- 183 Node regression cases: class records and concurrent edits, correction records/schedules, special-record edits, family page response ordering/cache/retry/detail/calendar, Alimtalk preview/delivery state, reminders/settings, and the nine new loader cases.
- 29 isolated PGlite family database cases: ownership, historical/period reports, record counts, previous homework and record reminders.
- Separate PGlite scripts: mixed makeup/additional student kinds and authorization; current exam selection for Alimtalk; stable lesson identity after timetable changes and private revisions.
- Production read-only integrity aggregates: zero duplicate active enrollments, schedule assignments, same-lesson attendance, special-lesson students, monthly tuition charges or recurring expense months; zero overpaid charges, charge-status mismatches or cancelled payments still in active payments.
- All 96 public tables have RLS enabled. Receipt storage is private. Reviewed expense/payment RPC authorization and stale-write checks; current_user_role excludes inactive accounts. RLS presence alone is not a complete permission proof.
- Vercel error/fatal runtime log query for the previous 24 hours returned no entries. This does not cover browser errors, every database error, or every Edge Function request.

## Limits and follow-up

- Cloud browser tab discovery timed out twice after setup; live authenticated administrator/teacher/family walkthroughs were not completed. Mock/unit/isolated-database results do not substitute for those walkthroughs.
- PGlite serializes statements; real multi-session lock contention was not measured.
- Supabase still reports existing advisory categories: callable security-definer functions, mutable function search path, leaked-password protection, and performance notices for RLS evaluation, policies and indexes. No new backend functions were added. Do not revoke callable RPCs or delete indexes solely from these categories; each requires dependency/access review.
- Security-definer functions without an explicit search_path: zero in the read-only query. The mutable-path advisor therefore is not evidence of an unprotected security-definer function.
- No real account creation/deletion, password reset, receipt upload, payment/expense mutation or message sending was performed.
